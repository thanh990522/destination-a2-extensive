Quản lý homework

Chọn Unit để xem cấu trúc, mở bản xem trước, sao chép link gửi học viên hoặc chỉnh sửa câu hỏi. Hạn nộp và đóng/mở homework nằm ở tab 🔓.

Chỉnh sửa nội dung (JSON)

Mỗi phần (part) có items. Câu chọn: {"q":"…","o":["A","B"],"a":"A"} · Điền từ: {"q":"I ___ here.","a":"live"} · Chọn trong câu: {"q":"She {is|are} here.","a":"is"} · Trả lời ngắn: {"q":"Where is Mum?","a":["at the market","market"]} · Nhiều đáp án đúng: "a":["don’t","do not"]. Phần viết/nói: "auto": false.

Kết quả học viên

Dữ liệu từ Google Sheet: mỗi lần học viên mở bài, nộp từng phần homework, gửi bài viết.

1 · GitHub key (để lưu đóng/mở bài và homework)

Key chỉ lưu trên trình duyệt này và chỉ gửi tới GitHub.

  1. Mở GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → destination-a2-extensive.
  3. Permissions → Repository permissions → Contents: Read and write → Generate → copy.

2 · Google Sheet (theo dõi tiến độ và homework)

  1. Tạo Google Sheet mới → Extensions → Apps Script.
  2. Dán toàn bộ code bên dưới, đổi dòng ADMIN_KEY thành mật khẩu riêng → Save.
  3. Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone → Deploy.
  4. Copy Web app URL → dán vào ô dưới → Lưu lên website.
Đang tải…

Web app URL (lưu lên website để học viên gửi kết quả)

ADMIN_KEY (chỉ lưu trên trình duyệt này, dùng để tải kết quả)

3 · Điểm đạt chung và thiết bị giáo viên

Thiết bị giáo viên luôn xem được bài đã khoá và không bị hỏi tên. Thiết bị được đánh dấu tự động khi GitHub key hợp lệ.
